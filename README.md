# 🚗 AutoCare - Symfony Booking System

Modernes Fahrzeugpflege- und Buchungssystem entwickelt mit Symfony.

---

# ✨ Features

- Benutzer Registrierung & Login
- Admin Dashboard
- Service Verwaltung
- Online Terminbuchung
- Responsive Design
- Bild Upload System
- Buchungsverwaltung
- Moderne UI
- EasyAdmin Integration
- Benutzerprofil

---

# 🛠️ Technologien

- Symfony 7
- PHP 8
- Doctrine ORM
- MySQL
- Twig
- Bootstrap 5
- EasyAdmin Bundle
- VichUploaderBundle
- FontAwesome

---

# 🚀 Installation

```bash
git clone https://github.com/suhaibdarwish21/Symfony-booking-system.git

cd Symfony-booking-system

composer install
```

---

# ⚙️ Datenbank Setup

`.env.local` erstellen:

```env
DATABASE_URL="mysql://USER:PASSWORD@127.0.0.1:3306/database_name"
```

Dann:

```bash
php bin/console doctrine:database:create

php bin/console doctrine:migrations:migrate
```
